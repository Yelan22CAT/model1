# 11 — Layered Context and Memory Governance

## Purpose

Keep long-running AI-assisted work useful without treating every past message as equally important or allowing summaries to replace source evidence.

## Public-safe structure

```text
Current task / working context
→ retrieve relevant prior evidence and lessons
→ verify provenance and freshness
→ use only what is needed now
→ archive non-current material behind a recoverable reference
→ promote durable facts or methods only after review
```

The method separates working context, episodic record, durable semantic facts, reusable procedures, and archived or superseded material.

## Controls

- Promotion is gated; repetition does not turn a claim into a fact.
- Freshness is scoped; historical facts remain historical while current-state claims can become stale.
- Conflicts stay visible; new material may support, supersede, or contradict earlier material.
- Pruning preserves traceability; leaving active context is not deletion.
- Memory is not authority: remembered ≠ understood ≠ verified ≠ authorized.

## Boundary

This public method does not publish private memory stores, thresholds, prompts, personal records, retention settings, or autonomous write-back logic.

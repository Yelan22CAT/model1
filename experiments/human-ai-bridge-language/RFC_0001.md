# RFC-0001 — What Should a Human–AI Shared Language Preserve?

> Open experimental question. Feedback is welcome.

## Problem

Humans communicate efficiently by leaving information implicit.

AI systems often generate efficiently by completing missing information probabilistically.

These two strengths can interact badly:

```text
human omission
+
model completion
=
semantic drift
```

The experiment asks whether a small shared language can make critical semantic states explicit without becoming too difficult for humans to use.

---

## Proposed invariant set

A useful shared language should preserve at least:

```text
WHO / WHAT       → entity
WHAT IS CLAIMED  → claim
HOW CERTAIN      → epistemic state
WHY              → evidence / derivation
WHAT IS MISSING  → unknown
WHAT IS WANTED   → goal
WHAT MAY HAPPEN  → action / transition
WHAT MUST HOLD   → constraint
WHO MAY ACT      → authority
WHAT WAS CHECKED → verification
WHEN             → time
```

---

## Questions for reviewers

1. Which distinction above is unnecessary?
2. Which critical distinction is missing?
3. Which symbol is visually ambiguous?
4. Does the notation remain readable to a programmer who has never seen Bridge-0?
5. Could a deterministic parser recover the same meaning without an LLM?
6. Which relationships should stay as words rather than become symbols?
7. Should the language remain one-dimensional text, or may 2D spatial layout become formal syntax?
8. What failure case would break the current design fastest?

---

## Contribution principle

The best contribution at this stage is a **counterexample**.

If a real task cannot be represented without ambiguity using the current primitive set, describe the task in synthetic form and show where the representation fails.

The language should evolve from demonstrated semantic gaps.

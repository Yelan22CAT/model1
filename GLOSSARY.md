# Glossary — Model 1 v1.0

This glossary defines only the public v1.0 vocabulary. Each term is deliberately narrow.

| Term | Definition |
| --- | --- |
| **Model 1 v1.0** | The public name of a minimal human-controlled judgment and stop-loss guardrail. It is not an AI model or execution engine. |
| **Protocol** | A small ordered set of checks used before a consequential next step. |
| **Guardrail** | A boundary-preserving check that can signal risk but cannot make a person's decision. |
| **Safety brake** | A mechanism for slowing, pausing, freezing, or exiting before further cost becomes difficult to reverse. |
| **Pre-execution** | Before the next consequential action is carried out. It may occur within an already ongoing situation; it does not mean speculative prediction. |
| **Consequential next step** | A proposed action that may increase cost, exposure, responsibility, lock-in, or irreversibility. |
| **Observation** | What is directly visible, recorded, or verified now. |
| **Hypothesis** | A bounded explanation that may fit the evidence but is not yet verified. |
| **Inference** | A conclusion drawn from evidence with its uncertainty and alternatives preserved. |
| **Unknown** | Information that is missing, mixed, stale, ambiguous, or not yet verified. |
| **Verification Pending** | A canonical state indicating that an important claim has not yet been checked sufficiently. |
| **Verified** | A claim that has been checked against an appropriate source and is currently supported. |
| **Deprecated** | An earlier judgment, state, or wording that is retained for history but is no longer active. |
| **Evidence direction** | A bounded statement of whether present evidence supports, fails to resolve, or opposes the proposed path. It is not an action approval. |
| **Balanced ternary** | The public `+ / 0 / -` direction vocabulary: support, unresolved, or oppose. |
| **`+` Support** | Current evidence supports the proposed path within the stated scope and time. |
| **`0` Unresolved** | Evidence is insufficient, mixed, or unresolved. Judgment should be preserved rather than forced. |
| **`-` Oppose** | Current evidence opposes the proposed path within the stated scope and time. |
| **Gray analysis** | Preserving partial support, uncertainty, degree, and alternative explanations instead of forcing binary certainty. |
| **Hard boundary** | A controlling safety, authorization, privacy, consent, contractual, validation, or personal limit that nuance must not wash away. |
| **Semantic localization** | Expressing the same canonical state in formal or plain language without changing its meaning. |
| **Stop-loss** | The act of limiting further cost once continuing no longer remains acceptably reversible or boundary-consistent. |
| **Boundary** | A stated constraint that the user is not willing to surrender merely to keep a process moving. |
| **Accumulating cost** | Increasing consumption of time, energy, exposure, responsibility, or integrity. |
| **Reversibility** | The degree to which a person can stop, withdraw, correct, or return to baseline without unacceptable loss. |
| **Risk signal** | A bounded prompt about how strongly the person should pause before acting; not a prediction, approval, instruction, or final decision. |
| **Green** | No stop-loss trigger is identified from the stated first-person input. No guarantee is provided. |
| **Yellow** | Risk is increasing; slow down, check evidence and boundaries, and preserve options. |
| **Red** | A hard boundary, mandatory validation gap, or irreversible-cost risk is present; freeze or exit is a reasonable option, subject to human decision. |
| **Two-axis output** | The separation of evidence direction (`+ / 0 / -`) from action-risk signal (Green / Yellow / Red). |
| **Freeze** | A temporary stop on further consequential movement while the user checks boundaries, evidence, and responsibility. |
| **Exit** | A decision by the user to stop participating in the relevant path or process. |
| **Reversal condition** | The evidence or condition that would materially change the current conclusion. |
| **Compact decision-support output** | A bounded format showing conclusion, decisive evidence, unknowns, reversal condition, and one safe next action. |
| **Closure awareness** | Recognition that an idea, demonstration, or fluent AI answer is not yet repeatable operation with ownership, maintenance, rollback, and responsibility. |
| **Human Final Gate** | The non-transferable requirement that a person makes and owns the final decision. |
| **First-person-only** | The restriction that the protocol evaluates the user's own exposure and next step, not another person's psychology or vulnerabilities. |
| **Anti-weaponization** | The prohibition on converting stop-loss judgment into influence, coercion, profiling, or control tactics. |
| **Editorial decoder** | A limited AI role that may format, translate, clarify, or compress while preserving meaning and boundaries. |
| **Public / private boundary** | Public v1.0 exposes minimal structure and safety limits; private cases, observer packs, thresholds, implementation internals, and execution layers remain excluded. |
